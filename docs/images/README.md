# Screenshot assets

Place real Home Assistant screenshots for the project README in this directory.

Recommended filenames:

- `dishwasher.png`
- `oven.png`
- `coffee-machine.png`
- `dryer.png`

After adding an image, enable its prepared Markdown block in the repository's main `README.md` by removing the surrounding HTML comment markers. Prefer cropped screenshots without personal information, hostnames, IP addresses, location names, or unrelated dashboard content.

The files `cards-preview.svg` and `cards-preview.png` are the existing generic project preview and should remain in place for HACS validation.
